# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository when it is
available. Otherwise, contact the repository owner through their GitHub
profile to request a private reporting channel.

Include the affected version, reproduction steps, potential impact, and any
suggested mitigation. You should receive an acknowledgement within seven days.

## Supported versions

The update manifest defines the currently supported version range. Versions
older than `minimumSupportedVersion` are unsupported and may be blocked from
normal application use when the manifest is reachable.
